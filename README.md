# Monday Morning Punchlines

Entry for the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc) bounty on make.fun.

One joke about Monday mornings, judged head-to-head by an AI judge on laughs, surprise, and freshness — no alarm clocks, no coffee, no "I hate Mondays". The entry personifies Monday as the week's unpaid intern: first in, least appreciated, blamed for everything.

## How to run

```sh
python3 main.py
```

This writes the joke (a single line, under 200 characters) to `/output/entry.txt`, creating `/output` if needed. Dependency-free — Python 3 standard library only, no network.
